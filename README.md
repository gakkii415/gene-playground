# Gene Playground

スマホ向けの遺伝子操作・学習シミュレータ。

https://gakkii415.github.io/gene-playground/?v=1

repository-creator 経由で作成。GitHub Pages は main のルートから公開します。index.html のみで動く静的アプリです。Google Fonts が利用できなくても操作できます。

## 実験

- GFP遺伝子を加える：働きの強さ、青い光と暗闇を比較。
- 紫のトマト：色素づくりの活性化と果実の成長を比較。
- 架空の花：2つの色素経路の働きを止め、組み合わせを比較。

これは教育用の模式図・簡略モデルです。DNA配列から形質を予測する科学計算ではありません。出典と限界はアプリ内に記載しています。
