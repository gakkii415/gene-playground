# Gene Playground

https://gakkii415.github.io/gene-playground/?v=2

スマホでDNAの編集を体験する学習用シミュレータ。repository-creator 経由で作成し、GitHub Pages の main ルートから公開。

## DNA editor

- 実在するEGFPのコード領域720文字を、1文字・3文字単位で選択。
- 書き換え・切り取り・1〜60文字の挿入。取り消し・やり直し・リセット。
- 編集した配列を標準遺伝暗号で読み直し、アミノ酸配列と最初の終了位置を計算。
- 同義置換・開始消失・早期終了・挿入削除を説明。青色変化は研究例に基づく模式表示。
- 任意の配列からタンパク質の形・実際の蛍光を予測するものではありません。未知の結果は未知と表示。

HTML/CSS/JavaScriptのみ。旧3実験は experiments.html に保存。ネットワークがなくても本体の計算は動きます（フォント・出典リンク除く）。

配列・科学的根拠へのリンクは画面内にあります。
